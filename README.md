# Unity Viewfinder-Inspired Project

A Unity project focused on recreating perspective-based mechanics inspired by *Viewfinder*, where 2D images interact with the 3D world.

## Features

* Mesh cutting into triangles for dynamic geometry
* Perspective capture using shaders
* Object cloning to create spatial illusions
* Frustum-based collision detection
* Object placement and rotation from captured images

## Challenges

* HDRP pipeline adjustments
* Rendering issues (terrain, skybox)
* Stability of core mechanics
